# 中文中间 Task 文档模板

用于方案澄清、事实补齐、用户确认和任务细化前的工作文档。生成文档时删除所有模板提示，不保留空占位符；没有内容时写“无”“未开始”“未运行”。

中间文档必须不可执行。它可以记录原始目标、沟通过程、待确认事项和粗粒度任务，但不得包含最终执行操作规则、完成情况检查规则或可执行任务格式。

中间文档可以记录尚未裁定的选择，但这些选择必须集中在待确认事项表或草案边界中。粗粒度任务不得把未裁定选择写成可执行步骤。
